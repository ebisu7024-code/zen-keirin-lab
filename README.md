# zenKeirin Lab

競輪の予想、買い目、結果、収支、心理・関係性の仮説を記録する個人用アプリです。

## できること

- レース情報の登録
- 選手ごとの能力、展開、心理、関係性評価
- 仮想バンク上でのライン隊列変更と展開予想
- 過去結果に基づくライン機能、番手差し、崩れなどの確率目安
- 選手別の位置ごとの1着率、3着内率、ライン機能率の確認
- 情報区分の記録（事実、本人発言、過去レース観察、Hypothesis、出所不明）
- 買い目、購入金額、払戻金の登録
- 着順入力による的中判定
- 的中率、回収率、券種別成績、競輪場別収支の確認
- 心理・関係性メモの振り返り
- 起動時に本日開催一覧と一部レース詳細を公開情報から更新

## 起動方法

```bash
cd /Users/zen/Projects/zen-keirin-lab
python3 -m pip install -r requirements.txt
streamlit run app.py
```

SQLiteのデータは `data/zen_keirin_lab.sqlite3` に保存されます。

起動・ブラウザ再読み込み時には、本日開催一覧を更新し、初期設定では最大5件まで選手・ライン・結果・払戻を補完します。件数は `ZEN_KEIRIN_STARTUP_HYDRATE_LIMIT` で変更できます。`0` にすると起動時の詳細補完を止め、開催一覧だけを更新します。

TIPSTARの購入結果は [TIPSTAR購入結果](https://tipstar.com/order/result) を参照リンクとして扱います。ログイン後の購入明細ページのため、レース情報・着順・払戻の公開補完はWINTICKET側の公開ページから取得します。

## 外出先で使う

推奨は Render Web Service + Persistent Disk です。`render.yaml` を用意してあり、公開時は `ZEN_KEIRIN_APP_PASSWORD` を設定すると簡易パスワード画面が有効になります。

詳しい手順は [docs/deployment.md](docs/deployment.md) を参照してください。

## 方針

このアプリは利益や的中を保証するものではありません。能力評価、展開評価、心理・関係性評価を分けて保存し、予想後に「どの判断が効いたか」を検証するための研究ノートとして使います。
